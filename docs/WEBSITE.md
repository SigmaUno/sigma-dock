# Canonical website

The project owner owns https://sigmadock.dev and has explicitly chosen to retain its existing website and hosting. The domain currently uses Namecheap DNS with the existing A record `185.158.133.1`. HTTPS serves the Sigma Dock landing page, with links to `/docs`, `/downloads` and the SigmaUno/sigma-dock GitHub repository. Workspace package homepages and the Homebrew tap point to this domain.

No DNS changes or redirects were made to the existing website. The pending custom-domain connection for an alternative landing-page draft was removed after the owner chose the existing site. The draft checkout remains separate from the application repository; it is not the production website source. The current website source/hosting is managed separately, and its canonical HTML metadata should be maintained there.

No sigmauno.com redirect was configured because that website's deployment settings are not available here. Changing the project homepage does not move the GitHub repository or existing local application data.
