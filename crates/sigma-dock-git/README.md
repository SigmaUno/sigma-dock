# sigma-dock-git

Part of [SigmaDock](https://github.com/SigmaUno/sigma-dock), a native, local-first workspace for supervising coding agents.

Early prototype for Linux and macOS, licensed under Apache-2.0. Package APIs may change before 1.0. No analytics, crash uploads, update checks, or remote logs are implemented by SigmaDock. Agent CLIs have independent network behavior.

See the [project README](https://github.com/SigmaUno/sigma-dock#readme) for setup and the [architecture](https://github.com/SigmaUno/sigma-dock/blob/main/docs/ARCHITECTURE.md) for this crate's responsibility. Project website: [sigmauno.com](https://sigmauno.com).
