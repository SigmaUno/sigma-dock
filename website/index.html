A workspace for the whole loop

Keep parallel work understandable.

One worker, one worktree

Each task gets an isolated git worktree, branch, and PTY. The daemon keeps agents running when you close the window.

Facts drive the board

See session activity, pull requests, checks, and reviews together. Send failures and review feedback back to the owning worker.

Use your agent CLI

Adapters support Claude Code, Codex, Gemini CLI, OpenCode, and Aider. Connect GitHub or your Forgejo instance.

Get started

Start on your own machine.

macOS preview

Open the GitHub releases page and choose a macOS testing release with a universal DMG. The app supports Apple silicon and Intel on macOS 13 or later. Testing builds are ad-hoc signed; notarized production installers and Homebrew distribution are still being prepared.

Linux and source builds

Follow the repository setup instructions for system dependencies and Cargo commands. Install an agent CLI separately and configure its own provider credentials.

No application telemetry

Local logs. No tracking.

SigmaDock has no analytics, crash reporting, or remote log shipping. Forge access uses your configured endpoint. GitHub update checks are opt-in. Agent CLIs have their own network and telemetry settings, which you control separately.
